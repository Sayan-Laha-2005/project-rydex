# Rydex 🚗

A full-stack vehicle booking platform built with Next.js, MongoDB, Socket.IO, and ZegoCloud.

## Structure

- `rydex/` - Frontend + API routes (Next.js)
- `socketServer/` - Real-time Socket.IO server

## Tech Stack

Frontend:
- Next.js
- React
- TypeScript
- Tailwind CSS

Backend:
- Next.js API Routes
- MongoDB
- Mongoose
- Socket.IO

Features:
- User authentication
- Partner onboarding
- Vehicle management
- Admin dashboard
- Video KYC
- Real-time communication
